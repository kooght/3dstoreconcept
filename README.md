# GendTools — Outils Gendarmerie

Suite d'outils pratiques pour faciliter le travail quotidien des militaires de la Gendarmerie nationale.

## Outils disponibles

| Outil | Description |
|-------|-------------|
| **Vitesse / Distance / Temps** | Calculs de cinématique routière pour reconstitution |
| **Garde à vue** | Chronomètre avec limites légales (24h / 48h) |
| **Coordonnées GPS** | Conversion DMS ↔ décimal |
| **Distance GPS** | Distance entre deux points (formule de Haversine) |
| **Calcul d'âge** | Âge précis à une date de référence |
| **Estimation alcoolémie** | Estimation théorique (formule de Widmark) |
| **Référentiel infractions** | Codes et sanctions du Code de la route |
| **Numérotation PV** | Générateur de références de procès-verbal |
| **Convertisseur d'unités** | Vitesse, distance, poids |
| **Chronomètre** | Chronomètre d'intervention avec tours |

## Démarrage

```bash
npm install
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000).

## Avertissement

Ces outils sont des aides à la décision. Ils ne se substituent pas aux textes officiels, aux appareils homologués ou aux procédures en vigueur.
